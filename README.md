## 🌟 About

This repository hosts the static files for [polycaman.github.io](https://polycaman.github.io/), a GitHub Pages blog where I share technical articles and insights about various topics in computer science, blockchain technology, and programming.

The blog aims to make complex technical concepts accessible and understandable through clear explanations, interactive demos, and practical examples.

## 📚 Content

The blog features technical articles including:

### Local Development

To view this site locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/polycaman/polycaman.github.io.git
   cd polycaman.github.io
   ```

2. Open `index.html` in your web browser:
   ```bash
   # On macOS
   open index.html
   
   # On Linux
   xdg-open index.html
   
   # On Windows
   start index.html
   ```

Alternatively, you can serve the files using a simple HTTP server:

```bash
# Using Python 3
python -m http.server 8000

# Using Python 2
python -m SimpleHTTPServer 8000

# Using Node.js (if you have http-server installed)
npx http-server

# Using PHP
php -S localhost:8000
```

Then navigate to `http://localhost:8000` in your browser.
